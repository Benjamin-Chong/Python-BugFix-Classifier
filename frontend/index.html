What is a bug-fix pattern?

A software fix is more than just corrected code. It can change an assignment, a function call, program control flow, an identifier, an expression, or even more. This project explores whether machine-learning models can recoginize those patterns directly from a before and after code diff.

Bug-Fix Category

Labels + Brief Explaination

  1. Assignment - Changes to stored values or assignment statements
  2. Call - Changes to function or method calls
  3. Control Flow - Changes to conditions, loops, or branching
  4. Expression - Changes to operators evaluateed expression
  5. Identifier - Changes to variable, function, or attribute names

Dataset Notes + CTA

The project is based on simplified bug-fix categories derived from the RunBugRun dataset. Predictions are model outputs, not guarantees of a fix’s correctness.
