What is a bug-fix pattern?

A software fix is more than just corrected code. It can change an assignment, a function call, program control flow, an identifier, an expression, or even more. This project explores whether machine-learning models can recognize those patterns directly from a before and after code diff.

Bug-Fix Category

Five Selected Categories

  1. Assignment - Changes to assignment targets, values, or operators.
  2. Call - Changes to function or method calls, including arguments.
  3. Control Flow - Changes to conditions, loops, branches, or jumps.
  4. Expression - Changes to expressions or operators, including arithmetic and comparisons.
  5. Identifier - Changes to variable, function, method, or attribute names.

Dataset Notes + CTA

The project is based on simplified bug-fix categories derived from the RunBugRun dataset. Predictions are model outputs, not guarantees of a fix’s correctness.
